# carton 0.17.5

> **仓库改名 `carton`，README 重写。** 功能逻辑不变，改的是项目身份与文档。

## 仓库改名

GitHub 仓库 `AI-phone-use-bypanzhihe` → **`carton`**。旧地址仍然能访问（301 重定向到新地址），
但**本地 clone 的 remote 需要手动更新一次**：

```bash
git remote set-url origin git@github.com:panzih/carton.git
```

名字来源：`carton` 就是「纸板箱」，对应中文品牌「纸盒」。全称
`Carton Automates Real Tasks On-device, Natively` 是递归缩写 —— 每个词首字母正好拼回 `CARTON`：

| C | A | R | T | O | N |
|---|---|---|---|---|---|
| **C**arton | **A**utomates | **R**eal | **T**asks | **O**n-device | **N**atively |

## 应用本身没有改名

- 桌面上的名字仍然是**「纸盒」**（`app_name`），无障碍服务名也是「纸盒」。
- 包名仍然是 `com.aiphone.assistant`。

**这是刻意的**：改包名等于换了一个应用，所有老用户都无法覆盖安装，
必须卸载重装（会清空本地设置、对话和记忆）。改名只在项目/仓库层面，不在安装标识层面。

## 其它

- Release 附件的 APK 文件名前缀 `AI-phone-` → `carton-`，例如
  `carton-v0.17.5-official.apk`。
- 系统提示词里的项目地址同步换成新仓库，因此 `AgentPrompt.VERSION` 11 → 12，
  老上下文按设计重开一次（这些改动之前已有的对话历史会重新建立缓存前缀）。
- README 重写：新增「关于名字」一节和仓库目录索引。

## 兼容性

- 动作协议、模型通道、免费车道、权限页、定时任务、副屏、录制均未改动；可直接覆盖安装。
- 版本号 0.17.5 / versionCode 95。
