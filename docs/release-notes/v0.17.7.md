# carton 0.17.7

> **总结出来的记忆，现在会像一条普通消息一样并进主循环。**

## 之前

记忆写进文件，但文件只在**新开上下文**时才会注入系统提示词。
所以这段对话里的 AI 看不到刚写的那条 —— 要等你手动清空上下文才生效。
记忆明明记下了，紧接着问它，它却不知道。

## 现在

归纳成功后，那条记忆会作为一条消息追加到模型历史末尾：

```
（记忆）常用系统设置查看存储

- 常打开系统设置看存储空间
- 喜欢先看「内部存储」那一项
```

下一次任务的第一条请求就带着它。你不需要清空上下文。

## 几个刻意的选择

- **标成 assistant，不是 user**：这不是你说的话。标成 user 会让 AI 以为
  你在给它下新指令，可能照着「记忆」里的文字去执行。
- **只追加在末尾**：上下文缓存按前缀逐字节匹配。末尾补充不改动任何早先
  内容，已缓存的部分照常命中；在中间插入会让后面全部重新计价。
- **写入失败就不加**：模型回「无」或和已有记忆重复时不追加，避免历史里
  堆一串没有信息量的条目。

## 一个边界情况

归纳在后台跑，可能比你发下一句话慢，也可能比它快。两种顺序都处理了：

- 先完成 → 先攒着，任务收尾时一起接上
- 后完成 → 发现历史已经收尾，当场追加
