# carton 0.17.10

> **「接下来你可能想做什么」改用缓存了。**

## 上一步错在哪

0.17.9 给出三条建议时，是拿一套**全新的上下文**去问模型的：自己的开场说明、
自己的一份记录。结果就是每次都把上下文从头算一遍，**一分钱缓存都没用上**。

可这条请求只想要三句话。任务越长、历史越多，这一下就越亏。

## 现在

改成**接着刚才那段对话问**：同一套开场说明、同一份历史，只在最后加一句
「根据上面刚做完的事，猜三件用户接下来最想做的」。

前面几十轮全部命中缓存，只多付那一句提问的钱。项目里的「复盘」一直是这么做的，
这次只是把建议也拉进来。

## 你能感觉到的

基本没有 —— 界面和行为完全一样，只是账单便宜了。任务越长省得越多。

## 兼容性

- 系统提示词、动作协议、模型通道、记忆链路、Beta 标注均未改动。
- 版本号 0.17.10 / versionCode 100。
