## 三条建议

任务结束、记忆总结完之后，AI 会再问自己一次：**刚才这一趟做完，我接下来
最可能想让它做什么？** 然后给出三条，显示在对话最底部：

```
接下来你可能想做什么
1  再看看内部存储还剩多少
2  把亮度调低一点
3  退出设置回到桌面
```

点一条就**填进输入框**，你可以改几个字再发。不直接执行 —— 建议只是草稿。

它只在你刚跑完任务后出现。发新任务或清空上下文就消失，因为那时你已经
自己决定了下一步。

**判断不出方向时它不会硬凑。** 如果这趟任务只是简单验证、或者失败得
没头绪，AI 会直接不显示 —— 三条没用的建议比没有更烦人。

## 修掉一个「永远看不到」的页面

之前的欢迎页（那个「说一句话，/ 剩下的交给它。」）只在**一条消息都没有**
时显示。但「清空并新开」会先清空、再塞一条「上下文已清空」的系统提示，
于是这个条件永远不成立 —— 欢迎页实际上只有全新安装那一瞬能看到。

现在只有系统提示时也算空白，欢迎页正常显示，系统提示放在它上面。

## 还没在真机上跑通的功能，都标上了 Beta

这些功能旁边现在有一个黄色的小 `Beta` 标记：

| 位置 | 功能 |
|---|---|
| 设置 → 行为 | 语音输入 |
| 设置 → 记忆与数据 | 悬浮条背景模糊、端侧提示挡路弹窗 |
| 设置 → 更多设置 | 允许 AI 在网页里执行 JavaScript、操作记录（实验）、看副屏画面 |
| 权限页 | 副屏 |

它们不是不能用，而是**没有在真手机上完整跑通过**。副屏依赖 Shizuku，
一直在模拟器上验证，真机还没验收；语音输入、毛玻璃、网页 JS 同理。
主通道（无障碍操作手机）已经验证，不受影响。
