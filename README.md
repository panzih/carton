# 纸盒 · carton

**说一句话，它替你在手机上把事做完。**

打开 App 打一行字——「打开 WiFi」「把屏幕亮度调低」「去设置里看看还剩多少存储」——
它自己看屏幕、找按钮、点下去、输入文字，一步一步做完，中间还会告诉你它打算干什么。

- **不用 root，也不用连电脑。** 装一个 APK、开一次无障碍权限就能用。
- **不挑应用。** 微信、抖音、设置、各种工具 App 都行，因为它点的是屏幕上真实存在的东西。
- **随时能喊停。** 觉得它要干的事不对，按一下「接管」，这一趟立刻结束。

---

## 一分钟：它到底是什么

它不是一个"语音助手"，也不是一个"自动化脚本工具"。区别在于：

| | 普通自动化工具 | 纸盒 |
|---|---|---|
| 谁来定步骤 | 你自己写规则、录脚本 | 你说目标，AI 每一步自己判断 |
| 界面变了怎么办 | 脚本失效，你自己改 | 它重新看一眼，接着做 |
| 会操作新 App 吗 | 得先有人写好 | 会，它没有内置的 App 名单 |

所以它擅长的是**那种"你懒得点七八下"的事**，而不是要求毫秒级精确的重复劳动。

代价也要说清楚：每一步都要问一次云端模型，所以**会花 API 费用**，而且比人手动点慢。

## 五分钟：从装到第一个任务

### 第 1 步 · 装

到 [Releases](https://github.com/panzih/carton/releases) 下载最新的
`carton-v<版本>-official.apk`，装的时候系统会问"允许安装未知来源应用"，同意即可。

> 安卓 9 及以上都支持。已经在用 0.13.0 或更早版本的话，签名不同，**不能覆盖安装**，
> 得先卸载旧版——卸载会清掉本地设置、对话和记忆。

### 第 2 步 · 开权限

打开 App，左侧抽屉进「权限」页，按提示去开**无障碍服务**。

这是唯一必须的一项：AI 靠它读屏幕、点按钮。悬浮窗权限建议一起开，
不然任务在跑的时候你看不到进度也停不下来。其余（通知、精确闹钟、麦克风）按需。

### 第 3 步 · 选模型

设置页顶部有个开关，两种模式二选一：

| 模式 | 适合谁 | 要准备什么 |
|---|---|---|
| **自定义模型**（默认） | 有 API Key 的人 | 一个 OpenAI 兼容的接口地址 + Key + 模型名。DeepSeek、OpenRouter、本地 Ollama 都行 |
| **免费模型** | 想先试试的人 | 什么都不用填。但这是社区共享的第三方网关，非官方、可能限流，**屏幕内容会发给它** |

免费模式**默认关闭**，第一次打开会弹一次风险说明，确认了才生效，随时可以切回来。

填完点「获取模型列表」，能连上就会把可用的模型列出来。

### 第 4 步 · 发第一个任务

在输入框里写一件事，点「发送」。建议第一件事选简单的，比如：

```
打开设置，看看还剩多少存储空间
```

然后看它做。做对了再试复杂一点的。

### 第 5 步 · 看懂底部那条悬浮条

任务一开始，屏幕底部会出现一条深色浮条，长这样：

```
当前：点开设置图标                    执行中
下一步：进入「存储」
[补充] [接管] [后台]              3/99 步
```

- **当前**：它正在做的那一步。
- **下一步**：它**打算**做的事——这是给你预判用的，觉得不对就在它发生之前按「接管」。
- **三个键**：

| 按键 | 什么时候按 | 按了会怎样 |
|---|---|---|
| **补充** | 想中途加一句话 | AI 停在下一个动作间隙，输入框亮起来，你补的话会并进这一轮 |
| **接管** | 这事不要了 | 这一趟立刻结束。已经做过的记录会留着，之后还能复盘 |
| **后台** | 想自己用手机 | AI 转到副屏继续干，主屏还给你（需要装 Shizuku） |

除了悬浮条，下拉通知栏里也有一个「急停」，作用和「接管」一样。

它每点一下，屏幕上那个位置会闪一圈蓝色水波——**能看见它到底点在哪儿**，
是点错了，还是点对了但界面没反应，一眼就能分辨。

## 它还能做什么

- **语音输入**：设置 → 行为里打开，输入框旁会出现麦克风。说完识别成文字**填进输入框**，
  你确认以后再发送，避免说错一个字就执行错动作。录音只在你点麦克风时进行，结束即停。
- **记住你的习惯**：打开「记忆」后，每次任务结束它会归纳一条记下来。
  下次开新对话自动带上，不用你重复交代。
- **自己开网页**：遇到需要看网页的任务，它会在应用里开一个内置浏览器，
  读的是网页结构而不是靠看截图猜，准确得多。
- **定时执行**：设定一个时间，到点自动跑，适合「每天早上看一眼天气」这类重复事。
  注意：手机必须**亮屏且解锁**它才操作得了，所以更接近"到点提醒你、你看着它干"，
  不是半夜无人值守。
- **副屏**：装了 Shizuku 之后，AI 可以在虚拟屏上操作，你同时正常用主屏。
  副屏读不到控件树，定位精度不如主屏，简单流程用它就好。
- **留证据**：每一步做了什么、模型返回了什么、当时的截图，全部留在手机本地。
  出问题可以在设置里一键导出 zip。

## 花钱这件事

它不是免费的，成本来自模型调用，按你选的接口计费。几个能省的地方：

- **「最大步数」是花费上限**：一次任务最多走多少步，每步一次调用。默认 99 步，
  简单任务根本用不到，觉得费钱可以调低。
- **思考强度别一直拉满**：简单操作（点开设置、看个信息）用低档就够了，
  高档主要对复杂判断有用。
- **它默认只发屏幕上的控件信息，不发截图**：截图贵得多，只有它判断"看不出来"时才要。

日志里的每一步都记了 token 用量，觉得哪次特别贵可以去查。

## 安全与隐私

- **你的 API Key 只存在这台手机上**，用系统密钥库加密，只有你填的那个接口能收到它。
- **屏幕内容、你打的字、你说的话会发给模型**——这是它工作的前提，没有例外，免费通道也一样。
  所以涉及密码、验证码、银行界面的任务，自己掂量。
- **支付、转账、删除、发送、授权、输入验证码/密码这类动作，默认直接被拦下**，
  根本不会执行。要放开得自己去设置里开「允许 AI 执行高风险操作」，
  开了以后每个高风险动作仍会单独过一次模型复核，结果写进日志。
- **没有广告、没有分析 SDK、不偷偷联网**。日志、截图、对话默认都只在本地，
  只有你主动导出才会离开手机。
- **导出日志前会提示风险**。文本里的 Key、密码、验证码会尽量打码，但**截图不做任何遮挡**，
  发给谁之前请自己看一眼。
- 应用里**没有检查更新的入口**，它不会为了查版本号去联网。想更新就回 Releases 页看。

## 常见问题

**点了发送没反应？**
先去「权限」页确认无障碍服务是开着的。没开的话它会提示你，输入框里的字不会丢。

**它看不见界面 / 一直说读不到元素？**
多数是无障碍服务被系统关了（有些机型清理后台会关），回「权限」页重开一次。

**输入中文失败了？**
部分输入框（尤其是自绘的）对 AI 的输入方式不友好。它写完会回读核对，
读不回来会如实说"无法确认"，不会假装成功。这种情况可以改成让它用剪贴板粘贴。

**任务跑一半卡住了？**
按「接管」结束，然后看设置里的日志。也可以在输入框里说「复盘」，它会对着上一趟给出结论。

**会不会乱点把手机点坏？**
高风险动作默认拦，而点击前它要先看清控件。但它是模型，会判断错——所以别在
支付、银行、政务这类界面上放着不管。

**为什么比我自己点慢这么多？**
每一步都要一次网络请求。它的价值在于"你不用自己动手"，不在于快。

## 从旧版本升级

- **0.14.1 起只有一个正式签名的包**，文件名带 `official`。
- 0.13.0 及更早版本、或装过 `-legacy.apk` 的，签名不同，**必须先卸载再装**，
  卸载会清空本地设置、对话和记忆。
- 2026 年 11 月之前的包都是开发者签名（私钥随仓库公开），任何人都能签出一模一样的包。
  所以发布线换成了独立密钥，旧线不再更新。

## 给开发者

<details>
<summary>项目结构、构建与测试、发布流程</summary>

单模块 Android 工程，Kotlin + Jetpack Compose + AccessibilityService + Shizuku。

```
app/src/main/java/com/aiphone/assistant/
├── MainActivity.kt       组装依赖、界面路由
├── ChannelController.kt  选通道、探前台、读控件树/截图
├── a11y/        无障碍服务：读控件树、点按、手势、截图
├── agent/       主循环：看屏幕 → 想 → 点 → 再看
├── browser/     内置浏览器通道（DOM 摘要映射成控件树元素）
├── channel/     设备通道抽象：无障碍 / 副屏
├── data/        设置持久化、上下文落盘、API Key 加密
├── display/     虚拟副屏：建屏、销毁、镜像
├── llm/         模型调用、模型列表、语音
├── log/         每步日志、自动截图、导出 zip
├── memory/      长期记忆
├── overlay/     悬浮条、落点水波
├── schedule/    定时任务
├── shell/       Shizuku / ADB 的 shell 服务（AIDL）
├── skill/       模型可调用的本地技能
├── task/        应用级任务状态与协程
├── touch/       手势与动作模型
└── ui/          Compose 界面
```

```bash
./gradlew :app:testDebugUnitTest   # JVM 单测（Robolectric，不需要设备）
./gradlew :app:lintDebug           # lint
./gradlew :app:assembleDebug       # debug APK
./gradlew :app:assembleRelease     # 正式签名包（需 keystore.properties）
```

CI 跑单测、lint 和 debug 构建；发布由 tag 触发，只出正式签名包并校验证书指纹。
任务主循环的设计见 [docs/architecture/agent-loop.md](docs/architecture/agent-loop.md)，
设备测试见 [docs/testing-device.md](docs/testing-device.md)，文档索引见 [docs/README.md](docs/README.md)。

**名字**：`carton` 就是"纸板箱"，对应中文品牌「纸盒」。
全称 `Carton Automates Real Tasks On-device, Natively` 是递归缩写，首字母拼回 `CARTON`。
仓库 2026-11 由 `AI-phone-use-bypanzhihe` 改名，旧地址 301 重定向；
应用名和包名 `com.aiphone.assistant` 故意没改，改包名会让老用户无法覆盖安装。
